1. What is an LLM?

LLM = Large Language Model. An artificial system (in essence a very large mathematical function) trained on huge amounts of text data.
  • Large: a huge volume of training data and a huge number of internal parameters.
  • Language: human language, i.e. text (including programming languages).
  • Model: a mathematical function that maps an input to an output, learned from data rather than hand-coded.

Everything about how LLMs work is hiding in the name GPT, so we unpack that next.

2. GPT: Generative, Pre-trained, Transformer

Generative

The model can produce new content based on what the user typed.

Pre-trained

Before you ever use it, the model has been trained on a vast amount of text: books, articles, websites, programming languages, and a large part of what is publicly available on the internet. When you ask a question, the answer is generated from patterns learned during that training.

Transformer

A special neural network architecture that can understand the user's text input in depth and then generate new text from that understanding plus what it learned in training. Google introduced it in 2017 in the research paper "Attention Is All You Need". Its key idea is the attention mechanism.

Clarification. The lecture says every LLM is "a GPT". Strictly, GPT is OpenAI's product family name. Gemini, Claude and others are transformer-based models doing the same core job (predicting the next token), but they are not all literally called GPT.

3. Attention: how the model reads context

Words can have several meanings. Take the sentence "The bank was too steep to climb." Does bank mean a financial institution or a river bank?

The attention mechanism lets the model relate every word in the input to every other word. While processing "bank" it also looks at "steep" and "climb". Money-related words are absent, and "steep" and "climb" suit a slope, so the model concludes river bank.

4. Next-word prediction loop

What does a transformer actually do? It predicts the next word (token) given the input. It does this repeatedly:

  1. Input: We finally sat. The model predicts the next word, e.g. down.
  2. Append it: We finally sat down. Predict again: on.
  3. Append: We finally sat down on. Predict: the.
  4. Append: ... on the. Candidates: bench, chair, floor, couch... The model picks the one with the highest probability: bench.
  5. When the model decides the answer is complete, it stops, and the final text appears in the UI.
In practice the model often does not always pick the single top word; settings like temperature add controlled randomness. That is one reason the same question can give different answers.

5. Tokens, token IDs and tokenization

Computers work in binary, so neither a computer nor an LLM can use raw text directly. Text must be converted into numbers. The process has steps:

  1. Split the input into chunks. Each chunk is a token. (A list of strings.)
  2. Map each token to a unique number using the model's own vocabulary (dictionary). These numbers are token IDs.
  3. Send the list of token IDs to the LLM.
  4. The LLM outputs token IDs.
  5. Decode the IDs back into tokens and join them into readable text for the user.

Key terms

TermMeaning
TokenA chunk of text produced by splitting the input (a word, part of a word, punctuation, or a space plus a word).
Token IDThe unique number the model's vocabulary assigns to a token.
TokenizationThe whole process of converting text to tokens and IDs.
TokenizerThe component that performs it (encode and decode).
Important. Every model has its own vocabulary, so the same text gets different token IDs in different models (for example GPT-3.5, GPT-4 and GPT-4o). Also, tokens are not always whole words: tokenizers often split into sub-word pieces, which is how they handle rare words.

6. Visualizer demo

Tools such as the Hugging Face tokenizer playground and the OpenAI tokenizer show this live. For the input Who is PM of India? the lecture shows 7 tokens:

Notice that the spaces attach to the following word, and "PM" splits into two pieces. Clicking "token IDs" shows 7 numbers. Switching the model (GPT-4o, GPT-3.5, GPT-3, GPT-4) changes the IDs, because each model uses a different dictionary.

7. Python implementation (Google Colab)

For this video the lecturer uses Google Colab to avoid local setup (later videos use a local environment). Steps: open Colab, create a new notebook, click Connect, and run cells with Shift+Enter. A quick test such as 5 + 5 returns 10.

Encode text to token IDs

!pip install tiktoken   # only if not already installed

import tiktoken

text = "Who is PM of India?"

# Tokenizer for a specific model (each model has its own vocabulary)
tokenizer = tiktoken.encoding_for_model("gpt-4")

token_ids = tokenizer.encode(text)
print(token_ids)        # a list of 7 numbers

The IDs match those shown by the online visualizer when the same model is selected.

Decode token IDs back to text

result_ids = [...]      # paste IDs, e.g. copied from the visualizer

result = tokenizer.decode(result_ids)
print(result)           # "PM of India is Modi ji" (exact original text)

Decoding returns exactly the original text with the same case and spacing. That is the round trip an LLM relies on: text to IDs, the model works on IDs, IDs back to text.

8. Context window

The context window is how many tokens a model can handle at once: how much you can send in and how much it can return. The lecture's analogy is a house with a front gate (input) and a back gate (output). The size of each gate limits how many people (tokens) can pass through at a time.

This explains the old ChatGPT behaviour where long conversations hit a "memory full" warning: the conversation had used up the model's context window. Newer models have much larger windows. (Technically, the window usually covers input and output together, and the whole chat history counts toward it.)

9. Max tokens and cost

Paid LLM providers (OpenAI, Google Gemini, Anthropic and others) charge by tokens, not by words or requests. You pay for:

  • Input tokens you send,
  • Output tokens the model generates (usually priced higher),
  • and any cached content stored for reuse (also charged, typically at a lower rate).

Example from the lecture's screen: roughly $1.25 per 1 million input tokens and $10 per 1 million output tokens for one OpenAI model. Prices differ by model and change often, so always check the provider's pricing page.

Why it matters for developers. When you call an LLM in code you can set a max_tokens limit for input and output. That caps cost and keeps responses within bounds. Later videos build this into real applications.

10. Revision and self-check

  • LLM = large model trained on huge text data; GPT = Generative Pre-trained Transformer.
  • Transformers (Google, 2017) use attention to relate words and understand context.
  • They predict the next token, append it, and repeat until the answer is complete.
  • Text becomes tokens, tokens become IDs via the model's own vocabulary; outputs are decoded back.
  • Context window = token capacity in and out; cost is billed per token.
  • tiktoken: encoding_for_model, encode, decode.
1. Why can't an LLM read text directly?

Computers work with numbers (binary), so text must first be converted to token IDs.

2. How does attention resolve the word "bank"?

It relates "bank" to surrounding words like "steep" and "climb", which point to a river bank.

3. Why do GPT-4 and GPT-3.5 give different IDs for the same sentence?

Each model has its own vocabulary mapping tokens to numbers.

4. What is the difference between a token and a token ID?

A token is a chunk of text; a token ID is the unique number assigned to it.

5. Why do tokens affect your bill?

Providers charge per million input and output tokens, so fewer tokens means lower cost.
